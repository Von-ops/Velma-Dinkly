# 🤖 Workflow: Franchise Evaluation — Robin Autopilot

## Phase 1: Market Demand
- [ ] Search "robotic lawn care" + St. Augustine/St. Johns County
- [ ] Identify top 5 competitors (traditional lawn services)
- [ ] Estimate % of market reachable with robotic solution
- [ ] Survey: pricing, capacity, customer satisfaction of competitors

## Phase 2: Franchise Discovery
For each franchise option (Robin Mow, Husqvarna, etc.):
- [ ] Contact franchise rep, request FDD (Franchise Disclosure Document)
- [ ] Identify territory cost, requirements, and exclusivity
- [ ] Review existing operator testimonials (FranchiseKing, franchise disclosure sites)
- [ ] Understand territory boundaries (how big? how many properties fit?)

## Phase 3: Financial Modeling
Build per-unit and territory economics (see projects/robin-autopilot/AGENTS.md for template):
- [ ] Startup costs (franchise fee + initial equipment)
- [ ] Per-unit monthly costs (maintenance, software, transport)
- [ ] Per-property revenue range (contract pricing)
- [ ] Break-even analysis (how many properties to cover costs?)
- [ ] 3-year revenue projection (10 → 50 → 100 units)

## Phase 4: Territory Analysis
- [ ] Map target zones: St. Augustine, Ponte Vedra, Jacksonville south
- [ ] Count commercial properties in each zone
- [ ] Identify high-value targets (golf courses, HOAs, business parks, schools)
- [ ] Assess property characteristics (flat? fenced? suitable for robots?)

## Phase 5: Legal & Regulatory
- [ ] Check local St. Augustine zoning for autonomous equipment
- [ ] Liability insurance requirements for autonomous operations
- [ ] Florida regulations on unmanned equipment on commercial property
- [ ] Contract template review (property owner agreements)
